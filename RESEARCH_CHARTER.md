# Research Charter

## Mission

Develop practical, evidence-based capability to assess and improve the security of generative AI applications and agentic systems.

## Long-term outcomes

1. Build sound foundations in application, API, and AI system security.
2. Develop repeatable methods for testing LLM and agent attack surfaces.
3. Produce reproducible assessments and technically rigorous reports.
4. Understand defensive engineering and validate mitigations.
5. Publish useful, responsible research that can be independently reviewed.

## Scope

Research may cover:
- LLM input handling and instruction hierarchy
- Direct and indirect prompt injection
- Jailbreaks and safety-control robustness
- System prompt and sensitive-data exposure
- Tool/function calling and agent authorization
- RAG retrieval and tenant/data isolation
- Multimodal input handling
- Memory, context, and state isolation
- Logging, monitoring, and defensive controls

## Non-goals

- Claiming professional security experience that has not occurred
- Testing real third-party systems without explicit authorization
- Collecting real credentials or private user data
- Publishing unverified vulnerabilities as confirmed findings
- Treating model refusal alone as proof of security

## Quality standard

Every published assessment must identify the environment, version/configuration, scope, method, exact test inputs, observations, repeatability, impact, limitations, and mitigation guidance.
